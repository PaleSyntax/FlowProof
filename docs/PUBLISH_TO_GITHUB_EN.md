# Publish FlowProof to GitHub yourself

This repository was prepared locally. No GitHub repository, pull request, tag,
release, visibility setting, description, or topic was changed by the release
preparation work.

## Before publishing

1. Read [`RELEASE_STATUS.md`](RELEASE_STATUS.md). Do not turn `NOT_VERIFIED`
   evidence into a public claim.
2. Confirm that `git status --short` is empty and note the exact commit:

   ```powershell
   git status --short
   git rev-parse HEAD
   ```

3. Run the commands in [`../README.md`](../README.md) from a clean clone.
4. Create or choose the professional GitHub account or organization that should
   own the public repository. Preserve the existing history; do not force-push.

## Publish the source

Replace the placeholder URL with the repository you created. Review the remote
before pushing; do not paste credentials into the command or repository.

```powershell
git remote -v
git remote set-url origin https://github.com/OWNER/FlowProof.git
git push -u origin codex/showable-niche-product
```

Open a pull request into `main`. Accept it only after every required GitHub
Actions job executes real steps and passes for the exact head. A run that ends
before executing steps is `UNKNOWN`, not PASS. Then merge without rewriting
history and update local `main`.

```powershell
git switch main
git pull --ff-only
git rev-parse HEAD
```

## Tag and release

Only after the verified commit is on `main`:

```powershell
git tag -a v0.6.0 -m "FlowProof v0.6.0"
git push origin v0.6.0
```

Create a draft GitHub Release from that tag. Attach only artifacts built and
verified from the tagged commit:

- source archive generated by GitHub;
- `FlowProof-Windows-x86_64-0.6.0.zip`, if the local status says it passed;
- `FlowProof-Windows-x86_64-0.6.0.zip.sha256`;
- sanitized machine-readable qualification evidence.

Download every uploaded asset again and compare its SHA-256 with the published
checksum before publishing the Release. Never move an existing tag. A later fix
becomes `v0.6.1`.

## Final public check

Use a signed-out browser or a fresh directory without cached credentials:

```powershell
git clone https://github.com/OWNER/FlowProof.git FlowProof-public-check
Set-Location FlowProof-public-check
git checkout v0.6.0
```

Confirm that the README renders, its links and screenshots work, the quick start
is reproducible, and no private remote or local path appears in public claims.
