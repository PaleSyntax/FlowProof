# Product metrics

## MVP technical metrics

- invariant evaluation latency;
- event ingestion latency;
- verifier latency;
- duplicate event rate;
- incident deduplication rate;
- recovery success rate;
- false-positive rate on demo fixtures;
- chaos scenario pass rate.

## Product metrics for a future pilot

- hidden incidents found that n8n marked successful;
- time to detect;
- time to recover;
- manual reconciliation time avoided;
- repeated side effects prevented;
- percentage of incidents with complete evidence;
- percentage resolved through a registered compensation;
- operator acceptance/rejection of proposed plans.

## Portfolio evidence

Do not invent production savings.

Report only measured synthetic/demo results, for example:

- 6 deterministic chaos scenarios;
- 100 repeated false_200 runs detected;
- zero duplicate invoices after repeated recovery request;
- incident detected within configured SLA;
- tests and environment used.

## Anti-metrics

Avoid vanity metrics:

- number of files;
- number of LLM agents;
- number of providers;
- raw test count without coverage of critical behavior.
