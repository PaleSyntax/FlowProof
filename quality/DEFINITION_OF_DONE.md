# Definition of Done

A feature is done only when:

- implementation exists;
- automated test covers core behavior;
- error case is covered;
- secrets/privacy reviewed;
- docs updated;
- actual check run;
- no false claim in README;
- commit is focused.

The overnight task is done only when:

1. false_200 demo path works;
2. incident has evidence;
3. recovery requires approval;
4. post-recovery verification resolves incident;
5. n8n JSON files exist and are validated as far as environment allows;
6. project starts through documented commands;
7. `NIGHTLY_REPORT.md` is honest and complete.
